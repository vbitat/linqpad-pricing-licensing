它能跑 C#、F#、VB.NET、SQL，能读写 Excel，能跑 xUnit 测试，能做 SQL 翻译，能引用外部程序集。你写一段脚本、连个库、看个结果，这些都没问题。

## 常见问题

**免费版有时间限制吗？**
没有。免费版是长期可用的版本，只是功能受限，不会到期失效。

**一个激活码能装几台电脑？**
单用户授权同时激活 3 台，另有 3 次虚拟机激活额度，额度用完后每年可转移激活 6 次。

**2027 年 11 月之后不续订会怎样？**
软件继续能用，已有功能不受影响，只是不再收到新版本更新。想继续拿更新需要续订。

**买 Pro 之后能补差价升 Premium 吗？**
官方提供升级路径，但不是简单补差价，具体金额和方式在购买时问清楚。这也是我建议一次买对档位的原因，升级往往比直接买贵。

**Windows 之外能用吗？**
macOS 有 beta 版，可以试但不建议作为唯一工作环境。Linux 没有官方支持。

**5 万多付费用户这个数字是真的吗？**
官方页面披露的：超过 5 万付费用户，包括 30 家财富 100 强公司和四家全球最大银行，最大企业客户是微软，免费版累计下载超过 500 万次。这个体量说明产品活得很好，不用担心哪天停止维护。
